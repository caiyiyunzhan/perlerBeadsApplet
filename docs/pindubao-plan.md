## 一、拼豆品类研究

### 1.1 拼豆是什么

拼豆（英文 Perler beads / fuse beads，又称熨烫豆、拼拼豆豆）是一种像素艺术手工：

- **材料**：空心塑料小圆管豆，常见材质为低密度聚乙烯（LDPE），直径分 **5mm 标准豆** 与 **2.6mm 迷你豆** 两档。
- **玩法**：按照图纸把豆子一颗颗插在带凸钉的拼板上，铺一层熨烫纸，用电熨斗中温熨烫，豆子受热熔合、冷却定型，成为一体的像素作品。
- **文化背景**：起源是欧美儿童手工教具，近年在国内因为像素艺术、动漫二创、表情包文化在成人手工圈爆火，常见作品包括动漫立牌、情侣头像挂件、冰箱贴、杯垫等。

### 1.2 玩法分类

**按形态**

| 玩法 | 说明 | 人群 |
|------|------|------|
| 平面拼豆 | 主流玩法，方形拼板单层拼摆熨烫 | 全人群 |
| 立体拼豆 | 多片平面件组合成盒子、人偶、摆件等立体结构 | 进阶玩家 |
| 异形拼豆 | 圆形、心形、星形、六边形等异形拼板 | 全人群 |

**按规格**

| 规格 | 特点 | 适合人群 |
|------|------|---------|
| 5mm 标准豆 | 颗粒大、易操作、容错率高，画面偏卡通色块 | 儿童、新手、教学 |
| 2.6mm 迷你豆 | 像素密度约 3.7 倍，画面细腻，可做写实肖像 | 16 岁+ 进阶、展示级作品 |

**按熨烫方式**

* 全熔：完全熔合，表面平整，最牢固。
* 半熔：保留豆孔立体感，观感更"像素"。
* 单面熔：背面熔合固定，正面保留豆形。
* 留孔熨法：局部不熔，留出穿绳孔做挂件。

**按成品应用**

钥匙扣挂件、冰箱贴、杯垫、立牌摆件、耳环饰品、画框装饰、车载挂饰等。

**特殊豆材**：透明豆、夜光豆、珠光豆、荧光豆，用于特效点缀。

### 1.3 色号体系（色卡）

色号是拼豆的"硬通货"：玩家按色号购买散豆补货，图纸必须标注**色号 + 用量统计**，否则无法备料。不同品牌色号不通用，颜色有细微差异，官方建议同一作品用同一品牌。

| 体系 | 说明 | 色数规模 |
|------|------|---------|
| MARD | 国产性价比品牌，主推 168 色，颜色极全 | 168 色 |
| COCO | 国产品牌 | 约 150 色 |
| 漫漫 | 国产品牌，色号字母+数字 | 约 150 色 |
| 盼盼 | 国产品牌，纯数字色号 | 250+ 色 |
| 咪小窝 | 国产品牌，纯数字色号 | 280+ 色 |
| Perler | 国际品牌（美国），5mm 标准稳定 | 约 50 色 |
| Hama | 欧洲品牌，Midi 对应 5mm，教育场景多 | 约 60 色 |
| Artkal | 规格最全（5mm 硬豆 R 系列、2.6mm C/S 系列等） | 200+ 色 |

**关键结论**：本项目现有代码已有 MARD/COCO/漫漫/盼盼/咪小窝 **5 套色号、217 色**的 HEX 映射表（`src/utils/colorData.ts`），是极有价值的种子数据，新项目必须继承，并把色卡从"前端写死"升级为"数据库 + 接口动态下发"，以后新增品牌不发版。

### 1.4 用户画像与核心旅程

**用户群体**

1. 学生 / 年轻女性手工爱好者（主力）：做动漫角色、表情包、情侣挂件。
2. 亲子家庭：儿童启蒙手工，5mm 大颗粒为主。
3. 进阶玩家：写实肖像、2.6mm 迷你豆大作品。
4. 半商业用户：手工店代做、市集摊主，需要高效出图纸和备料清单。

**核心旅程（图片转图纸场景）**

找图 / 拍照 → 裁剪构图 → 选风格滤镜 → 选尺寸（对应板子大小）→ 选色卡（品牌）→ 控制颜色数 → 预览成品效果 → 生成图纸（色号+用量）→ 按图纸摆豆熨烫 → 完成打卡。

**痛点（产品机会）**

1. 图片转图纸目前依赖电脑工具，手机端体验缺失。
2. 色号对照混乱，各品牌互不通用，新手不知道选哪套。
3. 备料难：不知道买哪些色号、各买多少。
4. 好图纸分散在社交平台，没有聚合的模板库。
5. 摆豆过程漫长，缺乏进度管理和打卡激励。

### 1.5 竞品参考

* **PixelBeads**（pixel-beads.com）：免费网页工具，图片转图纸 / 画布绘制 / 文字转图纸三入口，本地浏览器处理，高清导出，附社区作品集和完整选豆教程。弱点是纯网页、无小程序、无社区激励、无豆库管理。
* **现有开源小程序**（本项目）：画布编辑 + 图片导入 + 图纸导出 + 5 套色号，弱点是无后端、模板广场未启用、色卡写死在前端、无裁剪/风格化。

## 二、产品定位

> **拼豆堡 = 手机上最好用的拼豆图纸工具 + 活跃的拼豆模板社区。**

一句话：让任何人 3 分钟把一张图变成"色号 + 用量 + 可直接照着拼"的专业图纸；让玩家在模板广场找图、晒图、打卡，形成内容飞轮。

**差异化抓手**

1. 色卡系统产品化：多品牌色卡动态切换、色号搜索、"我的豆库"缺料提醒。
2. 图纸质量：专业减色算法 + 色卡最近色匹配 + 成品效果预览（圆孔质感渲染）。
3. 社区飞轮：官方模板保底 + 用户投稿激励 + 完成打卡晒图。
4. 备料闭环：图纸一键生成"缺料购物清单"（色号 x 数量），远期对接材料包电商。

## 三、小程序端功能规划

### 3.1 首页 / 模板广场（Tab 1）

* 瀑布流模板卡片：预览图、标题、网格尺寸、色数、点赞/收藏/使用数。
* 分类频道：推荐、动漫角色、表情包、文字数字、动物、食物、节日、风景、肖像、立体组合。
* 搜索：标题/标签/色号。
* 官方模板 + 已审核用户投稿混合展示，可按来源筛选。
* 模板详情：大图预览、色号用量列表、"一键使用"（跳编辑器加载）、收藏、举报。

### 3.2 图纸工坊（核心工具，Tab 2）

四个入口：

1. **图片转图纸**（核心中的核心）
   * 相册/拍照导入。
   * 裁剪：自由比例 + 预设比例（1:1、4:3、16:9），旋转、镜像。
   * 风格处理：原图、卡通增强（减色+描边）、复古、高对比、柔和、黑白；人像模式（肤色卡优先、细节保留）。
   * 尺寸选择：宽 8-200 格，按 5mm/2.6mm 显示对应的成品实际尺寸（如 58 格 x 5mm = 29cm）。
   * 色卡选择：MARD / COCO / 漫漫 / 盼盼 / 咪小窝（后续 Artkal、Perler、Hama）。
   * 颜色数控制：8-100 色滑杆，实时预览。
   * 高级选项：抖动算法开关（Floyd-Steinberg）、跳过背景色、透明背景转白色。
   * 生成：预览成品效果（圆孔渲染）+ 图纸页（网格+色号+坐标+用量统计表）。
2. **自由绘制**：网格画布（继承现有编辑器）+ 画笔/橡皮/吸管/填充/直线/矩形、参考底图描摹（半透明）、撤销重做、色卡选色。
3. **文字转图纸**：输入文字/字母/数字，选字体与粗细，自动生成。
4. **描摹模式**：上传参考图半透明垫底，逐格描点（手作还原玩法）。

### 3.3 我的（Tab 3）

* 我的作品：进行中 / 已完成 / 收藏的模板，支持进度打卡（按 10x10 分块勾选）。
* 我的豆库：登记已持有色号与数量；生成图纸时自动标记"已有/缺料"，生成缺料清单（可复制文本）。
* 导出历史：图纸 PNG / PDF（PDF 远期）。
* 设置：默认色卡、默认尺寸、清除缓存。

### 3.4 内容与引导

* 新手教程：拼豆是什么、工具清单、熨烫技巧（图文 + 视频），运营后台可维护。
* 色卡百科：全部色号色卡对照浏览 + 搜索（色号查颜色 / 颜色查色号）。

## 四、Web 管理后台规划

### 4.1 模块

1. **登录与权限**：管理员账号，角色分超管 / 运营 / 审核。
2. **色卡管理**：品牌、色号、色名、HEX、排序维护；小程序端接口动态下发；支持 Excel 批量导入。
3. **模板管理**：上传模板（网格数据 JSON + 预览图 + 分类标签 + 来源标记）、编辑、上下架、排序、推荐位配置。
4. **投稿审核**：审核队列，预览大图 + 数据校验，通过 / 驳回（附理由），先审后发。
5. **用户管理**：用户列表、搜索、封禁/解封、用户作品管理（违规下架）。
6. **内容管理**：教程文章、公告、Banner、分类标签字典维护。
7. **数据看板**：DAU、图纸生成量、模板热度榜、投稿量/审核通过率、留存概览。

### 4.2 技术选型建议

* 前端：Vue 3 + Vite + Element Plus（与小程序同为 Vue 技术栈，团队认知成本低）。
* 部署：云服务器 / 容器平台均可，注意 HTTPS 与微信 request 合法域名配置。

## 五、技术架构建议

### 5.1 总体

```
微信小程序（Taro 4 + Vue 3 + Pinia + TS）
        |
微信云开发（推荐 M1-M2）           自建后端（M3+ 可选演进）
  云函数（API）                    Node.js (NestJS) + MySQL
  云数据库（文档型）                + Redis（热模板缓存）
  云存储（图片/OSS）                + OSS（图片）
        |                                  |
        +--------- Web 管理后台（Vue 3 + Element Plus）---------+
```

**云开发 vs 自建**：

* 云开发：免运维、免备案、免域名白名单，云函数 + 云数据库 + 云存储开箱即用，适合快速上线验证；缺点是迁移锁定与复杂查询弱。
* 自建：完全可控、便于后续多端（H5/App）与电商扩展；代价是服务器、备案、运维。
* 建议：**M1/M2 用微信云开发快速上线**，数据模型按可迁移设计（JSON 文档结构），M4 若商业化验证成功再评估迁移自建。

### 5.2 核心算法（图片转图纸）

1. 裁剪与缩放：目标网格尺寸重采样（canvas，area 平均抗锯齿）。
2. 风格化滤镜：LUT/像素操作（描边用 Sobel，卡通用双边滤波近似或简化减色+边缘保留）。
3. 减色：Median Cut 或 K-means（K = 用户选的颜色数）。
4. 色卡映射：每个颜色在目标品牌色卡中找最近色，推荐 CIEDE2000（Lab 空间），至少用加权 RGB 距离。
5. 抖动（可选）：Floyd-Steinberg 误差扩散，提升照片类过渡效果。
6. 输出：网格颜色索引矩阵（压缩存储）+ 用量统计（色号 x 数量）+ 高清图纸 Canvas 导出 PNG。

### 5.3 数据模型草案（文档型）

```
user         { openid, nickname, avatar, status, createdAt }
colorBrand   { key, name, sort, enabled }
color        { brandKey, code, name, hex, sort }
pattern      { title, category, tags[], gridW, gridH, brandKey,
               cells (压缩索引串), colors [{code, hex, count}],
               previewFileId, source: official|user, authorId,
               status: draft|pending|published|rejected,
               likeCount, favCount, useCount, createdAt }
artwork      { userId, patternId?, title, cells, brandKey,
               progressBlocks [], status: doing|done, createdAt }
beadItem     { userId, brandKey, code, count }
submission   { patternId, userId, reviewStatus, reason, reviewedAt }
```

### 5.4 内容安全与合规（微信审核硬门槛）

1. UGC 必须接微信内容安全接口：图片 `imgSecCheck` / 异步 `mediaCheckAsync`，文本 `msgSecCheck`。
2. 投稿先审后发：机器审 + 人工审双保险。
3. 举报通道 + 违规下架流程。
4. 版权：官方模板用原创/无版权素材；用户投稿协议要求原创授权；提供侵权投诉入口。
5. 隐私：相册/头像等权限用途说明，隐私协议接入微信隐私弹窗。

## 六、商业化思路（打开思路）

1. **免费 + 激励视频广告**：高清无水印导出、批量转换解锁看广告，最轻的变现起点。
2. **会员订阅**：高级滤镜/人像模式、批量生成、PDF 导出、专属会员模板、更大云空间。
3. **缺料清单 -> 电商闭环**（远期）：图纸生成色号清单后，展示"一键配齐材料包"，自营发货或带货分销（拼豆品牌合作）。
4. **品牌合作**：与 MARD 等国产拼豆品牌联名官方色卡、定制模板，导流线下。
5. **社区活动**：每周主题挑战赛（节日热点），带动留存与 UGC。

**暂不建议**：初期不做付费模板抽成等重运营模式，先把工具口碑和模板量做起来。

## 九、关键风险

1. **微信审核**：UGC 小程序类目资质（社交/社区类可能要求个人主体不可用，需企业主体）、内容安全接口接入完整性是最大门槛。
2. **图片存储成本**：模板预览图与图纸图走云存储，需压缩 + CDN + 生命周期策略。
3. **算法效果**：色卡映射准确度决定口碑，需要建立测试图集持续调参（人像/风景/动漫分别调优）。
4. **版权风险**：动漫角色模板天然高风险，投稿协议 + 审核标准 + 投诉通道三件套必须齐。
