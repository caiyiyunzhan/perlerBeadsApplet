# 「拼豆堡」项目全量规划 v2.1（纯工具版）

> 版本：v2.1（2026-09-05）
> 主体假设：**个体工商户 / 个人主体小程序**，以"工具-效率"类目过审。
> 配套文档：`docs/pindubao-plan.md`（品类研究）、`docs/pindubao-ux-spec.md`（拼豆模式与换色交互规格）

---

## 〇、本版重大调整说明（v1.0 → v2.0）

### 2.0 定位红线（不可违反）

1. **纯工具**：只有工具能力与官方只读内容，没有任何用户间交流。
2. **零支付**：无任何付费、充值、打赏、会员、电商入口。
3. **零 UGC**：无投稿、点赞、评论、关注、晒图、私信、广场。
4. **零 AI 外呼**：不接入任何第三方 AI / 大模型接口，全部处理在本地完成。
5. **本地优先**：用户作品数据存本地，可导出文件备份，不上传用户数据。

### 被删除的功能及原因

| v1.0 功能 | 删除原因 | 替代方案 |
|-----------|---------|---------|
| AI 优化生图 | 成本高，个人主体不接用户自有 API，自配 AI 成本不可控 | A05 本地卡通化增强（离线描边+色块简化算法） |
| 用户投稿 / 点赞 / 晒图 / 举报 | UGC 属交流性质，个体户难审难过 | D 官方模板库（只读，运营方上传） |
| 微信登录 + 作品云同步 | 减少个人信息收集，降低审核与合规面 | E03 图纸文件导出/导入备份 |
| 意见反馈表单 | 表单属双向交互形态 | H03 关于与帮助（静态 FAQ） |
| 订阅消息通知 | 无审核流程则无通知场景 | 删除，无需替代 |
| 激励视频广告 / 会员 / 任何付费 | 零支付红线 | 删除，工具完全免费 |
| 管理后台的用户/审核/举报模块 | 无用户系统无 UGC | T 内部运营工具（只管模板与色卡数据） |

### 过审策略（个体户）

* 类目：工具 > 效率（备选：图片/照片处理）。
* 首页即工具入口，无社交氛围、无用户昵称头像展示、无热度互动。
* 模板库为官方只读内容（等同内置素材），不发用户内容。
* 相册 / 相机权限用途说明齐全，隐私协议明确"图片本地处理"。
* 不申请位置、通讯录、麦克风等敏感权限。

## 一、项目概览

### 1.1 产品定位

**拼豆堡 = 一部手机就能用的专业拼豆图纸工具箱。**

把任意图片变成"色号 + 用量 + 可直接照着拼"的图纸；内置官方模板库、色卡百科、豆库与计算器；全程本地处理，不需要账号，不需要联网（模板库更新除外）。

### 1.2 版本边界

| 版本 | 定位 | 周期 | 核心目标 |
|------|------|------|---------|
| M1 工具版 | 纯本地工具，图片转图纸全链路 | 8 周 | 工具可用，过审上线 |
| M2 模板库版 | 官方模板库 + 内部运营工具 | 4 周 | 内容更丰富，模板可持续更新 |
| M3 增强版 | 豆库、计算器、教程、导出增强 | 4 周 | 留存与实用深度 |

总工期 16 周，M1 第 8 周提审上线。

### 1.3 成功指标（上线后 3 个月）

* 图纸生成成功率 ≥ 95%，100 格生成 ≤ 3 秒（中端安卓）。
* 次日留存 ≥ 25%，7 日留存 ≥ 10%。
* M2 后官方模板 ≥ 200 个，覆盖全部分类。
* 无任何审核驳回记录（保持零 UGC / 零支付红线）。

## 五、数据设计（本地优先）

### 5.1 小程序本地存储（Taro Storage）

```
artwork       { id, title, gridW, gridH, brandKey, cells(RLE),
                colors[], progressBlocks[], doneColors[],
                status, updatedAt }
favoriteTpl   { templateId, savedAt }
beadInventory { brandKey, code, count, storageSlot }
settings      { defaultBrand, defaultSize, defaultGridStep }
recentTpl     { templateId, usedAt }

```

### 5.2 云端配置数据（云开发只读，无用户写入）

```
colorBrand    { key, name, version, enabled }
color         { brandKey, code, name, hex, lab[], symbol,
                series, autoMatchable, sort }
templatePack  { version, publishedAt, templates[] }
template      { id, title, category, tags[], gridW, gridH,
                brandKey, cells(RLE), colors[], previewFileId }
guideArticle  { id, chapter, title, content, sort }
```

要点：

* 云端只有配置与内容，不存任何用户数据。
* 模板数据 RLE 压缩 + 分包加载，控制包体积。
* 色卡与模板均版本化，客户端增量拉取。

## 六、测试与上线清单

### 6.1 功能测试重点

* 量化算法回归：40 张测试图集固定参数对比基准快照。
* 色卡校验：291 色无重复、HEX 合法、系列正确。
* 导出：iOS/Android 相册保存成功率、打印可读性。
* 本地数据：作品/收藏/豆库在清理缓存提示下的保护逻辑。
* 文件备份：导出文件在新设备导入还原一致。

### 6.2 性能指标

| 指标 | 目标 |
|------|------|
| 100 格生成 | ≤ 3 秒（中端安卓） |
| 300 格生成 | ≤ 10 秒且可取消 |
| 编辑器帧率 | 缩放拖动 ≥ 50fps |
| 模板库首屏 | ≤ 1.5 秒 |
| 冷启动 | ≤ 2.5 秒 |

### 6.3 上线前检查清单

1. 全程无 UGC / 无支付 / 无 AI 接口 / 无社交能力自检通过。
2. 类目与页面内容一致（工具属性，首页即工具）。
3. 相册 / 相机权限用途说明与隐私协议一致。
4. 用户协议、隐私协议、备案信息齐全。
5. 本地数据清理有二次确认。
6. 云端仅配置数据，无用户信息收集声明。
7. 灰度：首个版本先小流量发布观察崩溃率。

## 九、风险与应对

| 风险 | 等级 | 应对 |
|------|------|------|
| 工具类目审核仍被驳 | 高 | 首页纯工具化；删除一切可能被判定内容的氛围元素；备选图片处理类目 |

| 本地数据丢失投诉 | 中 | 引导文件备份；关键操作二次确认 |
