# 「拼豆堡」项目全量规划（PRD + 开发计划）

> 版本：v1.0（2026-09-05）
> 配套文档：`docs/pindubao-plan.md`（品类研究与立项依据，本文引用其结论不再重复）

---

## 一、项目概览

### 1.1 产品定位

**拼豆堡 = 手机上最好用的拼豆图纸工具 + 活跃的拼豆模板社区。**

让任何人在 3 分钟内把一张图变成"色号 + 用量 + 可直接照着拼"的专业图纸；让玩家在模板广场找图、晒图、打卡，形成内容飞轮；远期为线下拼豆店提供 B 端工具。

### 1.2 版本边界

| 版本 | 定位 | 周期 | 核心目标 |
|------|------|------|---------|
| M1 工具版 | 纯本地工具小程序，无账号无后端 | 6 周 | 跑通图片转图纸全链路，建立工具口碑 |
| M2 社区版 | 云开发后端 + 登录 + 模板广场 + 审核后台 | 6 周 | UGC 内容飞轮启动 |
| M3 增长版 | 豆库、缺料清单、打卡、教程、看板、广告 | 4 周 | 留存与初次变现 |
| M4 扩展版 | 会员 / B 端拼豆店 / 更多色卡 / 立体图纸 | 按需 | 商业化验证 |

### 1.3 成功指标（上线后 3 个月）

* 图纸生成成功率 ≥ 95%，单图生成耗时 ≤ 3 秒（100 格内）。
* 次日留存 ≥ 25%，7 日留存 ≥ 10%。
* M2 后月投稿 ≥ 500，审核通过率 ≥ 60%。
* 管理后台审核时效：投稿 24 小时内处理率 ≥ 90%。

关键设计点：

* cells 用颜色索引 + RLE 压缩存储，百万格以内体积可控。
* color.autoMatchable 标记透明等特殊色是否参与自动量化（如 H1 为 false）。
* 色卡带版本号，小程序按版本增量拉取，新增品牌不发版。

## 六、测试与上线清单

### 6.1 功能测试重点

* 量化算法回归：40 张测试图集固定参数出图，对比基准快照。
* 色卡校验：291 色无重复色号、HEX 合法、系列归属正确。
* 导出：不同尺寸图纸在 iOS/Android 相册保存成功率。
* 审核：机审拦截样例全部命中。
* 权限：三种后台角色越权访问全部拒绝。

### 6.2 性能指标

| 指标 | 目标 |
|------|------|
| 100 格图纸生成 | 不超过 3 秒（中端安卓） |
| 300 格图纸生成 | 不超过 10 秒且可取消 |
| 编辑器帧率 | 双指缩放拖动不低于 50fps |
| 模板列表首屏 | 不超过 1.5 秒 |
| 后台审核列表 | 1 万条数据不超过 2 秒 |

### 6.3 上线前检查清单

1. 微信类目与主体资质：UGC 需企业主体 + 社区类目。

3. 隐私协议、用户协议、权限用途弹窗齐全。
4. 举报与侵权投诉入口可达。
5. 管理后台强口令 + 操作日志开启。
6. 数据库每日快照备份。
7. M2 灰度发布：先 10% 用户放量。
