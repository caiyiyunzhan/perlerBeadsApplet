# 「拼豆堡」用户场景与交互细节规格

> 版本：v1.0（2026-09-05）
> 定位：补足 `pindubao-full-plan.md` 里"拼豆进行时"的细节规格。
> 核心原则：**玩家不是在"看图"，是在"边看边摆豆"。** 工具的每处交互都要为"眼睛在图纸和拼板之间来回切换、一只手拿镊子、容易串行串列"这个真实姿态服务。

---

## 一、用户是谁：8 类画像与真实目的

| 画像 | 场景 | 打开小程序的目的 | 最在乎什么 | 我们给什么 |
|------|------|----------------|-----------|-----------|
| 1. 跟图新手 | 买了材料包 / 网上找图，照着拼 | 找一张能照着拼的图纸 | 图纸清楚、色号看得懂、不数错 | 官方模板库 + 大字色号 + 按色筛选 |
| 2. 自创图玩家 | 想把自己喜欢的照片/画稿做成拼豆 | 图片转图纸，控制效果 | 转出来像不像、颜色准不准、豆子买不买得到 | 量化管线 + 色卡映射 + 缺料清单 |
| 3. 复刻党 | 看到别人的成品想还原 | 成品照片转图纸 | 细节还原度、色数控制 | 高格数 + 精修 + 仿真豆粒预览 |
| 4. 挂件小件党 | 做钥匙扣、冰箱贴送人 | 快速出小图 | 快、色少、好拼 | 小尺寸快捷档 + 按色模式 |
| 5. 大幅写实党 | 2.6mm 肖像、大作品 | 高密度图纸 + 分块管理 | 分块看图不乱、进度不丢 | 分区进度 + 底板接缝 + 文件备份 |
| 6. 亲子家长 | 周末陪娃做手工 | 找简单图案、照着摆 | 简单、大格、色少 | 24/48 色板 + 16/24 格 + 教程 |
| 7. 拼豆店到店顾客 | 在店里现场拼，店家出图 | 快速选图开拼 | 选图快、看得清 | 模板库分类 + 平板大屏模式 |
| 8. 手工摊主 | 批量做货售卖 | 批量出图、算成本 | 效率、成本、用料 | 成本计算器 + 材料表导出 |

**共同点**：所有画像最终都要落到"照着图纸摆豆"这一步。所以"拼豆模式"（看图摆豆的界面）是全产品使用时长最长的界面，比生成器还重要，必须做到极致。

## 二、核心场景深拆：拼豆进行时的一分钟

真实摆豆姿势还原：

```
拼板摆在桌面，平板/手机放旁边显示图纸
左手扶板，右手拿镊子夹豆
看一眼图纸 -> 找到当前色号的下一格 -> 摆豆 -> 再看一眼
每分钟重复 10-20 次，一幅 3000 豆的作品要重复几千次
```

这个循环里每次"看图纸"的微动作，就是功能的来源：

| 微动作 | 会出什么问题 | 对应功能 |
|--------|-------------|---------|
| 找"当前色号的下一格在哪" | 全图密密麻麻找不到 | 按色号筛选，只显示这一色 |
| 确认在第几行第几列 | 眼睛来回跳，串行串列 | 行列十字高亮 + 行号列号大字 |
| 记这一行要摆几颗 | 数错，多摆漏摆 | 每行计数徽标 |
| 记哪些已经摆过 | 回头重复找 | 已摆格子标记变暗 |
| 区分 A14 和 A15 这种近似色 | 拿错豆 | 近似色警示 + 大色块对照 |
| 图太小看不清色号 | 眯眼 | 放大镜 + 平板横屏大格 |
| 晚上拼，屏幕太亮刺眼 | 眼睛累 | 深色模式 |
| 手上有汗/油碰到屏幕 | 误触改了图 | 图纸锁定只读模式 |
| 摆完一色换下一色 | 忘了摆到哪 | 逐色打卡 + 自动切下一色 |
| 中途休息再回来 | 进度丢了 | 自动保存进度 |

## 三、拼豆模式（P 组）交互规格

### P01 按色号筛选显示（用户点名，最高优先级）

* 图纸页提供色号列表（按用量降序或色号排序），点选任一色号后：**图纸只显示该色号的格子**，其余格子隐藏或压暗为 8% 透明度底图。
* 三种显示强度可选：只看此色 / 此色高亮其余半透明 / 全部显示。
* 切换色号时图纸保持当前缩放与位置，不跳回全图。
* 规格依据：玩家按色批量摆豆（先把一色摆完再换下一色），全色显示下找某一色极度低效。

### P02 已摆格子标记

* 单击格子 = 标记已摆（变暗 + 打勾角标），再点取消。
* 支持框选批量标记（这一片都摆完了）。
* 撤销标记有 5 步撤销栈。
* 已摆数量实时统计：当前色 128/346。

### P03 行列十字高亮

* 点击/长按任意格，该行该列整条高亮，行号列号放大显示。
* 每 5 格/10 格加粗辅助线（默认每 10 格，5mm 板可切每 29 格）。
* 规格依据：从图纸到实物板的对位靠行列数，十字线把"数格子"变成"看位置"。

### P04 每行计数徽标

* 筛选某色号后，每行行号旁显示该行此色的颗数（如"第 12 行 x4"）。
* 已全部标记完成的行整行划线置灰。
* 规格依据：一行摆 4 颗，玩家可以一口气摆完再换行，不用逐格回看。

### P05 局部放大镜

* 长按任意位置出现浮层放大镜（2x/3x 可调），显示该区域色号。
* 放大镜内同时显示坐标（行 x 列）。

### P06 图纸锁定（防误触）

* 顶部锁形开关：锁定后图纸只读，只能缩放平移，不能标记/修改。
* 规格依据：摆豆时手汗触碰屏幕，误触改图会毁进度。

### P07 深色模式

* 图纸页独立深色模式：格子色保持原色，网格线和背景转深色，色号文字自动反色。
* 跟随系统 + 手动切换。

### P08 平板与横屏适配（用户点名，最高优先级）

* 支持横屏（landscape）：进入拼豆模式可解锁屏幕旋转。
* 横屏双栏布局：左侧图纸占 2/3，右侧色号列表 + 进度面板占 1/3；点击右侧色号即筛选。
* 平板（iPad / 安卓板）格子自动放大，格内色号字号三档可调（小/中/大），最大档在 10 英寸平板上每格色号仍清晰可读。
* 提供旋转锁定开关（有人习惯固定竖屏）。
* 规格依据：大量玩家用平板拼豆，屏幕大 = 一屏看更多格子，减少缩放次数；拼豆店到店场景几乎全是平板。

### P09 当前色实物对照

* 筛选色号时，界面顶部常驻大色块 + 色号 + 色名（如"A14 大红 #FD543D"），面积不小于 96x96px。
* 规格依据：色号文字不如色块直观，玩家要拿实物豆和屏幕比色。

### P10 近似色警示

* 当图纸中存在感知距离过近的两个色号（如 A14/A15）时，色号列表自动归入"易混淆"分组并标注提醒。
* 详情页显示两色并排大色块 + 差异说明。

### P11 分区进度

* 图纸按 10x10（可调 5x5 / 20x20）分块，每块可单独标记"完成"。
* 全局进度条 = 已完成块数 / 总块数。
* 规格依据：大作品（100x100 以上）逐格打卡不现实，按块管理进度。

### P12 剩余颗数递减

* 标记已摆后，该色号剩余数 -1；材料清单页同步刷新。
* 支持长按照某色"一键完成"（这一色我全摆完了）。

### P13 进度自动保存

* 所有标记、分区状态自动写入本地，中断后恢复。
* 进度数据随作品文件一起导出备份。

### P14 拼豆计时（可选）

* 开始拼豆时可启动计时，记录单幅用时。
* 纯本地，无排行榜无社交。

### P15 完成庆祝

* 全部格子标记完成后，整图点亮 + 简单动效（无分享要求，可保存纪念图）。

## 四、色卡定制与换色规格（用户点名）

### X01 整卡换品牌重映射

* 图纸生成后，可一键切换目标色卡品牌（MARD -> 盼盼等），系统保留网格结构，仅重新执行色卡映射，色号与用量统计随之更新。
* 切换前显示预览对比（前后小图），确认后生效。

### X02 整色替换

* 在色号列表中选择"把 A14 全部换成 A15"，全图该色号格子统一替换，用量重算。
* 替换可撤销。

### X03 单格点选换色

* 精修模式下点任意格，弹出当前品牌色卡（按系列分组）选新色号。
* 支持吸管取图中已有色。

### X04 色号排除重映射

* "这个色我没有/不想买" -> 排除后该色所有格子自动映射到剩余可用色中的最近似色。

### X05 只用我的豆库出图（杀手级）

* 生成图纸时可选"仅使用我已拥有的色号"（勾选豆库约束），量化只在用户拥有的颜色集合内匹配。
* 缺色时明确提示"若开启此选项，效果会略有损失"。
* 规格依据：这是"买豆难"痛点的终极解法——图直接迁就库存，而不是库存迁就图。

### X06 自定义色板

* 用户可从全色卡中手动勾选任意色号组合，保存为"我的色板"（如"我的一盒 72 色"），生成时选用。
* 色板可导出/导入文件备份。

### X07 生成前后对比

* 生成结果页提供原图 / 色块图 / 仿真豆粒三联对比滑动条。

## 五、熨烫前检查（配套场景）

* 孤豆提示：四周无相邻豆的格子列出（易脱落，建议加锚）。
* 分区检查：按块核对是否漏摆。
* 熨烫风格说明卡：部分熔 / 全平融 / 背熔三选一的建议文案。

## 六、物理世界适配（R 组，常被忽略但真实存在）

### R01 特殊豆纹理标记

透明豆、夜光豆、珠光豆、荧光豆与普通实色豆在实物上差异明显，但屏幕色块无法区分（H1 透明和 H2 白色可能显示成近似的白）。渲染规范：

* 透明豆：色块加斜纹纹理 + 半透明底。
* 夜光豆：色块角标月亮图标。
* 珠光豆：色块加珠光高光点。
* 荧光豆：色块加闪电角标。
* 图例常驻：图纸底部图例同时列出特殊豆说明，打印时同样保留标记。
* 色号列表中特殊系列（如 MARD 的 H1、ZG、P、R 系列）默认归入"特殊效果"分组，提示用户这些豆通常需单独购买。

### R02 图纸镜像切换

两种真实场景需要镜像：

1. 翻面熨烫（胶带法）：把豆从板上转移到胶带后翻面，此时从背面看图案是反的，图纸需要镜像对照。
2. 图纸垫在透明拼板下方：从正面透过板看图无需镜像，但部分玩家习惯把打印图反过来垫（防墨蹭板），需要确认方向。

规格：拼豆模式与图纸导出均提供"镜像"开关（水平翻转），行列标号不镜像（编号始终按用户视角），仅图案翻转；导出 PNG 时同样可带镜像。

### R03 1:1 比例尺打印

透明拼板玩家会把打印图纸直接垫在板下照着摆，此时格子必须是精确的实物尺寸：

* 5mm 豆：每格精确 5mm；2.6mm 豆：每格精确 2.6mm。
* 打印设置提供"1:1 实物比例"开关，并附 10cm 校准尺（打印后先用尺子量校准条，确认打印机没有缩放）。
* 提示用户在打印对话框中选择"实际大小"而非"适合页面"。
* 规格依据：一旦被打印机自动缩放，透明板和图纸就对不上位，这是打印场景最常见翻车点。

### R04 挂件孔位标注

做钥匙扣、包挂需要在图案上留穿绳孔（该格不摆豆，或摆豆后打孔）：

* 编辑器提供"孔位"标记工具，被标记的格子渲染为空心圆。
* 图纸导出时空心格显示为"留空"并计入图例。
* 常用孔位预设：顶部单孔、顶部双孔、左右侧孔。

### R05 异形拼板轮廓

除 29x29 方板外，真实存在圆形板、心形板、星形板、六边形板、小方板（如 14x14）：

* 画布可切换底板轮廓形状，图案区自动裁切到板型内。
* 用量统计只统计板内格子。
* 官方模板可标记适配板型。

### R06 黑白打印友好模式

很多玩家用家里黑白打印机出图：

* 提供"黑白模式"：格子用色号文字 + symbol 符号 + 灰度填充三重编码，确保黑白打印后仍可区分。
* 深色格自动反白色号文字。

### 补充：新手首次引导与无障碍

* 首次进入弹出三步引导：选图/模板 -> 生成图纸 -> 按色拼豆，每步一屏可跳过。
* 色弱友好：色号文字 + 符号双编码天然弥补色觉障碍；对比度符合 WCAG AA。
* 左右手习惯：行列号可设置显示在左/右、上/下两侧。

## 七、转换质量保障（Q 组，全链路自查）

### 7.0 先承认物理事实

用户上传的是连续 RGB 图，拼豆色卡是有限离散色集合（如 MARD 291 色）。**"和原图完全一样"在物理上不存在**，强行承诺只会翻车。产品目标不是消灭色差，而是把不可控的失真变成**可视、可控、可解释、可修正**。

### 7.1 全链路四道防线

```
第一道 转换前：图片预检 -> 背景治理 -> 复杂度分析 -> 多方案推荐
第二道 转换中：感知色匹配 + 黑白锚点 + 关键区域加权 + 杂色合并
第三道 转换后：还原度评分 + 差异热力图 + 色差报告（把问题亮给用户）
第四道 修正：整色替换 / 单格改色 / 局部重生成 / 排除重映射
```

### 7.2 具体翻车场景与对策

| 用户图片特征 | 直接转换会怎样 | 对策 |
|-------------|---------------|------|
| 颜色花里胡哨、背景杂乱 | 主体被背景色淹没，色数爆炸 | Q07 背景简化（虚化/纯色/移除）+ Q01 推荐合理色数 |
| 渐变天空/晚霞 | 被压成生硬色带 | Q08 抖动开关 + Photo 模式 |
| 人像肤色 | 肤色发灰发绿，人不像人 | Q05 关键区域保护（肤色/五官优先匹配） |
| 深色头发贴深色背景 | 糊成一团分不清 | 预处理对比度增强 + Q03 热力图暴露问题区 |
| 眼睛高光等微小细节 | 一格都占不下，直接消失 | Q01 分析细节密度，推荐更高格数方案 |
| 霓虹紫粉等色板外颜色 | 匹配到土味近似色，用户觉得"颜色错了" | Q10 色域预警 + 建议换色卡或接受风格化 |
| 图片本身很糊/很小 | 转出来全是马赛克 | Q11 上传预检，先提示换图 |
| 不知道选多大尺寸 | 选小了细节全丢，选大了拼不完 | Q01 多方案推荐 + Q06 并排对比 |

### 7.3 功能规格

#### Q01 智能像素方案推荐（用户点名，P0）

* 上传后自动分析图片复杂度：边缘密度（细节多少）、色彩熵（颜色丰富度）、主体占比、人脸检测。
* 输出 3-4 个候选方案卡（如 32 / 48 / 64 / 96 格），每卡标注：预估还原度、色数、总豆数、难度星级、成品实际尺寸。
* 默认高亮"推荐"方案，附一句推荐理由（Q12）。
* 用户仍可手动改，推荐不锁死。
* 回答"多少像素才完美"：不给唯一答案，给可选方案组，把专业判断产品化。

#### Q02 还原度评分（P0）

* 转换完成后计算感知差异（感知色差 + 结构相似度综合），输出 0-100 还原度分。
* 分级文案：90+ 优秀 / 75-89 良好 / 60-74 一般 / 60 以下建议调整。
* 低分时给出可执行建议：加色数 / 升格数 / 开抖动 / 简化背景。

#### Q03 差异热力图（P1）

* 结果页增加"差异"视图：把每格与原图对应区域的色差映射为热力色（偏差越大越红）。
* 点击热区可跳转该区域精修。
* 让用户一眼看到"哪里不像"，而不是笼统感觉"不像"。

#### Q04 色差偏差报告（P1）

* 列出偏差最大的前 5 个色号：原色 -> 被映射成的豆色、影响格数、偏差原因（如"该紫超出 MARD 色域"）。
* 每行提供"换色 / 排除"快捷操作入口。

#### Q05 关键区域保护（P1）

* 人像模式自动识别肤色、眼睛、嘴唇区域；这些区域的色号匹配加权重，禁止大幅偏色（宁可牺牲背景）。
* 主体与背景冲突时，背景让位。

#### Q06 多方案并排对比（用户点名，P0）

* 2-4 个方案（不同格数 / 色数）同屏并排缩略对比，支持滑动放大。
* 每个方案下方显示 Q02 评分与豆数，帮助用户做"效果 vs 工作量"取舍。

#### Q07 背景简化（用户点名，P0）

* 背景"花里胡哨"时提供三选：虚化（保留氛围去细节）/ 纯色化（换成单色）/ 完全移除（不计豆）。
* 自动检测主体，主体永远不被简化。

#### Q08 渐变抖动优化（P1）

* Photo 模式下提供 Floyd-Steinberg 抖动开关，文案解释取舍："更像照片，但同色区域会出现颗粒混合"。
* 插画 / 卡通图默认关闭抖动保色块纯净。

#### Q09 局部重生成（P2）

* 圈选一块区域（如脸部），单独用不同参数（更高色数 / 更细格数）重转，不影响其余部分。

#### Q10 色板外颜色预警（P1）

* 转换前扫描原图色彩是否超出目标色卡色域；超出比例高时明确提示，并给三条路：提高色数 / 换色卡品牌 / 接受风格化。

#### Q11 图片质量预检（P0）

* 上传时检测：分辨率过低、模糊、主体过小、极端长宽比、透明背景，逐项给修图建议。
* 严重问题直接建议换图，避免用户在烂图上浪费调参时间。

#### Q12 推荐理由说明（P2）

* 每个推荐方案附一句话解释，如"检测到人像与丰富渐变，建议 64 格 + 48 色"。
